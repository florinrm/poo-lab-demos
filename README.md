# POO Lab Demos

Acest repository conține demo-urile pentru laboratoarele de Programare Orientată pe Obiecte (POO) în Java.

## Slide-uri

Slide-urile pentru laboratoare se găsesc [aici](https://drive.google.com/drive/folders/1QdfazyRk_ZdlDVKWbid3nl3393ZtAIM1?usp=drive_link).

## Structură

Demo-urile sunt organizate pe laboratoare, în directorul `src`:

- `src/lab1` – laboratorul 1
- `src/lab2` – laboratorul 2
- `src/lab3` – laboratorul 3
